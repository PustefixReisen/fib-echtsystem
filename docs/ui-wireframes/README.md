# UI-Wireframes – strukturelle Referenz

Diese Wireframes dokumentieren den abgestimmten Stand des FIB-Redaktionssystems.

## Verbindlichkeit

Die Wireframes sind **inhaltliche und strukturelle Orientierung**:
- verbindlich: sichtbare Informationen, Zustände, Aktionen, Beziehungen, Reihenfolge und Gruppierung;
- nicht pixelgenau verbindlich: exakte Abstände, Größen, Spaltenbreiten, Feintypografie und responsive Detailanordnung.

Die verbindlichen fachlichen Regeln stehen in `docs/Redaktionssystem-UI-Konzept.md`.

## Enthaltene Referenzen

- Dashboard
- Arbeitskorb inkl. Federführung und Sperranzeige
- Meldungsdetail / Freigabe
- Vorgang
- Themenliste
- Recherche: Funde, Funddetail, Quellen, Beobachtungsaufträge
- Veröffentlichung: Freigaben, Medien & Dateien, Kommunikation, Besucherführung
- Auswertung: Besucher & Wirkung, Inhalte, Recherche
