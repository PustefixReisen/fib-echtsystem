## Archiv zu PR #259

Die mit `PR259-` beginnenden Arbeits-, Abgleich-, Migrations- und Abnahmedokumente sind keine konkurrierenden Fachkapitel. Sie werden als Entstehungs- und Prüfprotokoll unter [archiv/pr259/](archiv/pr259/) aufbewahrt.

Für die laufende fachliche Arbeit gelten die elf Kapitel und die darin integrierten Fachregeln. Historische Dokumente dienen der Nachvollziehbarkeit, nicht als zusätzliche Primärnorm.

## Dokumentationsprinzip

Fachliche Änderungen werden unmittelbar im zuständigen Kapitel dokumentiert. Bestehende Regelkennungen bleiben erhalten. Neue fachliche Entscheidungen werden nicht allein durch technische Umsetzung oder redaktionelle Umformulierung eingeführt.

Umsetzungslücken werden als GitHub-Issues erfasst; technische Detailentscheidungen bleiben von fachlichen Regeln unterscheidbar.
