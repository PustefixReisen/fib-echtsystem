# Tests

Testbereiche für FIB:

- `regression/` – fachliche Referenz- und Demonstrator-Transferfälle,
- `integration/` – Fachservices und Infrastrukturadapter,
- `e2e/` – Redaktions-App und öffentliche Website.

Die technische Automatisierung der bestehenden Referenzfälle wird schrittweise in U1–U6 aufgebaut.
