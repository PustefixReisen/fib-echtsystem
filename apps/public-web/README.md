# public-web

Öffentliche FIB-Webseite / PWA.

Verantwortung:
- Darstellung ausschließlich freigegebener K0-Inhalte,
- statischer Build,
- öffentliche Suche/Navigation/PWA-Funktionen.

Nicht hierher gehören:
- interne Fachlogik,
- Redaktions-Secrets,
- direkter regulärer Zugriff auf interne FIB-Tabellen oder Fachservices.

Framework-Initialisierung (Astro) folgt in U3 bzw. soweit für U1-Integration erforderlich.
