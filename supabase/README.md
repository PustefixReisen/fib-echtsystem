# Supabase

Reproduzierbare Supabase-Infrastrukturquelle für FIB.

Geplante Bereiche:
- `migrations/` – Schema, Constraints, Policies, Funktionen/Trigger,
- `functions/` – Edge Functions / Worker,
- versionierbare Konfiguration soweit technisch möglich.

Dashboard-only-Einstellungen werden zusätzlich im Betriebs-/Migrationsrunbook dokumentiert.
